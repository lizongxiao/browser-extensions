## web-update-alerts

页面更新时进行通知的插件

## 核心功能：

- 方便地圈选任何网页上您感兴趣的区域进行监控，一旦有更新立刻通知
- 多种通知方式（邮件、短信、微信、飞书/钉钉/企业微信群及 webhook 等）
- 非常直观的差异对比（保留原页面的布局和样式，高亮差异部分内容）
- 可以对圈选内容的变化设置过滤规则，忽略不感兴趣去的内容更新
- 可以设置监控的时间段
- 可以共享规则，一键添加别人共享的监控规则
- 可以共享监控任务，浏览器关闭也可以接受到更新
- 支持导入/导出规则，方便共享
- 支持云端监控或私有化部署
- 支持完备的脚本预处理，可以模拟操作，自定义数据
- 支持 android 设备（需要安装 kiwi browser）
