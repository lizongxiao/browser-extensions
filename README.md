# Web Update Alerts - 网页内容监控与更新提醒工具

网页内容监控工具是一个谷歌浏览器扩展，它可以帮助您监控特定网页元素或区域，当内容发生变化时通过通知提醒您。

## 主要功能

- **选择性监控**: 可以选择监控网页上的特定元素或整个区域
- **定期检查**: 自动按设定的时间间隔检查内容变化
- **即时通知**: 当监控的内容发生变化时，立即通过浏览器通知提醒
- **管理界面**: 在选项页中管理所有监控项目，查看更新状态

## 技术特点

- 使用 TypeScript 开发，提供类型安全和更好的开发体验
- 完全支持 Manifest V3，确保与最新的 Chrome 扩展规范兼容
- 使用 Vite 构建系统，提供更快的开发和构建体验

## 安装方法

### 从 Chrome 应用商店安装

1. 访问 Chrome 应用商店（链接待发布）
2. 点击"添加到 Chrome"按钮

### 从源代码安装

1. 克隆仓库: `git clone [仓库URL]`
2. 安装依赖: `npm install` 或 `pnpm install`
3. 构建扩展: `npm run build` 或 `pnpm build`
4. 在 Chrome 浏览器中打开 `chrome://extensions/`
5. 启用"开发者模式"
6. 点击"加载已解压的扩展程序"
7. 选择项目中的 `dist` 目录

## 使用指南

### 添加监控项

1. 访问您想要监控的网页
2. 使用快捷键 `Ctrl+Shift+U` (Mac: `Command+Shift+U`) 激活选择模式
3. 在页面上绘制选择区域，通过拖动鼠标选择您想要监控的内容
4. 根据提示选择:
   - 监控选中元素: 监控所选区域内的特定 HTML 元素
   - 监控整个区域: 监控绘制区域内的所有内容

### 管理监控项

1. 点击浏览器工具栏中的扩展图标
2. 选择"管理监控项"，或直接右键点击扩展图标并选择"选项"
3. 在选项页面中:
   - 查看所有监控项及其状态
   - 设置检查频率
   - 删除不需要的监控项
   - 查看内容变更

## 技术实现细节

本扩展主要包含以下关键组件：

1. **内容选择器**: 使用 Canvas 实现交互式区域选择
2. **元素检测器**: 基于 XPath 和 DOM 操作识别选中的元素
3. **内容比较器**: 保存并比较 HTML 内容以检测变更
4. **后台监控器**: 定期在后台打开页面检查内容变化
5. **通知系统**: 使用 Chrome 通知 API 提醒用户变更

## 优化细节

最近的优化包括:

- 增加了保存页面 URL 和元素 HTML 数据以便更准确地进行内容比较
- 改进了元素选择算法以提高选择精度
- 添加了类型定义以增强代码安全性和维护性
- 优化了选项页面，提供更友好的用户界面展示监控列表
- 实现了更高效的内容对比机制以降低误报率

## 隐私说明

- 本扩展只会访问您明确选择监控的网页
- 所有监控数据仅存储在您的浏览器本地，不会上传到任何服务器
- 扩展不会收集任何用户信息或浏览历史
